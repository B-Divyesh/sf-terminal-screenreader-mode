# Changelog

## 0.1.0 — 2026-08-28

- Wrap commands and linearize standard output and standard error.
- Preserve stdout and stderr records in child write order through one shared pipe.
- Remove ANSI control sequences and overwritten spinner frames.
- Label headings, errors, and links in text or JSON Lines output.
- Keep timestamps on by default and earcons off by default.
- Include a local sample demo that writes only to a temporary directory.
